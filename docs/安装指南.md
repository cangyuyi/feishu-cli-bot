# 📦 飞书办公小助手 · 同事安装指南

> 这是给你（同事）看的**最简安装教程**。不用懂代码，跟着步骤复制命令就行。
> 全程在你**自己的 Mac** 上运行，连接的是**你自己的飞书账号**，数据不出本机（只有大模型推理走你自己的 API key）。

---

## 一、你需要先准备什么

| 准备项 | 说明 | 怎么确认 |
|--------|------|----------|
| 一台 Mac | 本教程针对 macOS（Windows 请看 `windows/README-Windows.md`） | — |
| Python 3.9+ | 系统一般自带 | 终端跑 `python3 --version`，看到 `3.9.x` 以上即可 |
| `lark-cli` | 飞书官方命令行工具（如果你装了 WorkBuddy，它已经自带） | 终端跑 `lark-cli --version`，能输出版本号就 OK |
| 大模型 API Key | 任意一个 OpenAI 兼容接口：火山方舟豆包 / OpenAI / 通义 / 本地 Ollama 都行 | 自己到对应平台申请 |

## 二、拿到项目代码

**方式 A（有 Git）：**
```bash
git clone https://github.com/cangyuyi/feishu-cli-bot.git
cd feishu-cli-bot
```

**方式 B（没有 Git）：**
打开 https://github.com/cangyuyi/feishu-cli-bot ，点绿色的 `Code` → `Download ZIP`，解压后 `cd` 进文件夹。

## 三、确认 lark-cli 并授权飞书

### 1. 先确认命令在不在
```bash
lark-cli --version
```
- ✅ 输出版本号 → 跳到「2. 授权」
- ❌ `command not found` → 你的 `lark-cli` 没在终端 PATH 里，按下面修一下：

```bash
# 找一下本机 lark-cli 在哪（WorkBuddy 用户通常在下面这个位置）
LARK_PATH=$(find "$HOME/.workbuddy" -name lark-cli -type f 2>/dev/null | head -1)
echo "找到：$LARK_PATH"

# 软链接到系统路径（以后终端就能直接用 lark-cli）
sudo ln -s "$LARK_PATH" /usr/local/bin/lark-cli

# 重开一个终端窗口，再验证
lark-cli --version
```
> 如果 `find` 没找到，说明你机器上确实没装 lark-cli。装了 WorkBuddy 的话它在应用包内，可在 WorkBuddy 设置里找到；或按飞书官方文档安装飞书 CLI。

### 2. 授权飞书
```bash
lark-cli auth login
```
按终端提示，在浏览器里登录**你自己的飞书账号**，并授予 **im（消息）/ calendar（日历）/ task（任务）** 权限。
（如果之后某些功能报「无权限」，再补跑 `lark-cli auth login --domain calendar` 等对应命令即可。）

## 四、配置大模型（LLM）

复制配置模板，填你自己的 key：

```bash
cp config/feishu_bot_env.example ~/.feishu_bot_env
chmod 600 ~/.feishu_bot_env
```

用任意文本编辑器打开 `~/.feishu_bot_env`（访达里按 `Cmd+Shift+G` 输入路径也能找到），改这三项：

```ini
# 火山方舟豆包（示例，换成你自己的）
FEISHU_BOT_LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
FEISHU_BOT_LLM_KEY=你的-key
FEISHU_BOT_LLM_MODEL=doubao-seed-2-1-pro-260628
```

> 用别的模型也行：OpenAI 填 `https://api.openai.com/v1` + 你的 key + `gpt-4o-mini`；通义/DeepSeek/Ollama 同理，都是 OpenAI 兼容接口。

## 五、告诉机器人「监听哪个会话」

机器人需要知道在飞书的哪个私聊里听你说话。拿到这个会话的 `chat_id`：

```bash
lark-cli im +chat-list --types=p2p,group
```

终端会列出你最近的会话，找到你想用来和机器人聊天的那个**私聊**（比如「文件传输助手」或你自己的某个对话），复制它的 `chat_id`（长这样：`oc_xxxxxxxxxxxxxxxxxxxxxxxxxxxx`）。

回到 `~/.feishu_bot_env`，把这一行填进去：

```ini
FEISHU_BOT_CHAT_ID=oc_这里换成你刚复制的id
```

## 六、启动机器人

```bash
cd feishu-cli-bot          # 如果不在项目目录了，先 cd 回来
bash scripts/launch.command
```

看到终端打印「已启动看门狗」就成功了。关掉终端窗口也没关系，它会在后台继续跑。

## 七、验证一下

打开飞书，进入刚才填了 `chat_id` 的那个私聊，发一句：

```
你好
```

几秒内机器人应该回你一段自我介绍。能回 = 成了 🎉

## 八、（推荐）开机自动启动

不想每次手动开终端？把它加进登录项，以后 Mac 开机自动跑：

```bash
bash scripts/add-login-item.command
```

「系统设置 → 通用 → 登录项」里会多一个 `launch.command`，搞定。

## 常见问题

**Q：发消息没反应？**
- 看日志：`tail -f bot-poller.log`，一般会有报错原因。
- 最常见：第 5 步的 `chat_id` 填错（填成了别人的会话），或第 4 步的 LLM key 无效。

**Q：想让它「只能看不能改」？**
打开 `~/.feishu_bot_env`，把 `FEISHU_BOT_ALLOW_WRITE=1` 改成 `0`。这样它只回复、不帮你建日程/发消息。

**Q：怎么彻底停掉？**
```bash
pkill -f feishu-bot-watchdog
```

**Q：想清空聊天记忆重来？**
```bash
python3 -m feishu_bot --clear
```
